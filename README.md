# The Sky Sanctum

Home page for https://theskysanctum.com. Other projects are served from their own repos under it, for example `/skycare`.

To add a project: turn on GitHub Pages for its repo with no custom domain, and it appears at `theskysanctum.com/<repo-name>`. Then add a card for it in `index.html`.
